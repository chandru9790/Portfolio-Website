CHANDRU M — PORTFOLIO WEBSITE
=============================

Files
-----
- index.html : portfolio content and page structure
- style.css  : responsive visual design, layout and animations
- script.js  : scroll reveal, scroll progress, mobile menu and current year

How to run
----------
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Double-click index.html to open it in a browser.
4. For development, open the folder in VS Code and use the Live Server extension.

Before publishing
-----------------
- Confirm all resume details and dates are current.
- Replace the illustrative project mockups with screenshots of your real projects.
- Add live demo and repository links to the project cards if available.
- Check the email, LinkedIn and GitHub links.
- Publish the folder using GitHub Pages, Netlify or another static hosting provider.

This site uses plain HTML, CSS and JavaScript. Google Fonts are loaded online; the page still works if they are unavailable.
